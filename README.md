# Prompt Engineering & LLM Behavior Analysis

## Overview
This project explores how different prompt engineering techniques influence the behavior, accuracy, and reliability of Large Language Models (LLMs) in text-based question answering tasks.

The study focuses on comparing outputs generated by ChatGPT and Gemini using multiple prompting strategies while analyzing:
- hallucination
- ambiguity
- instruction adherence
- response consistency
- output structure

The project demonstrates how prompt refinement and structured prompting can significantly improve AI-generated responses.

---

# Objectives

- Analyze LLM behavior across different prompt styles
- Compare ChatGPT and Gemini outputs
- Study hallucination and over-generalization in AI responses
- Improve response quality through prompt refinement
- Explore structured prompting techniques such as JSON-based prompts

---

# AI Tools Used

- ChatGPT
- Gemini AI

# Prompt Engineering Techniques Explored

## 1. Zero-shot Prompting
The model answers questions directly without prior examples.

### Focus:
- factual extraction
- concise answers
- hallucination control

---

## 2. Few-shot Prompting
The model is guided using example question-answer pairs.

### Focus:
- output consistency
- format control
- better instruction following

---

## 3. Role-based Prompting
The AI is assigned a specific role/persona.

### Roles Explored:
- Sports Tutor
- Academic Expert
- Sports Analyst
- Critical Thinker

### Focus:
- contextual alignment
- tone adaptation
- domain-specific responses

---

## 4. JSON-based Prompting
Structured prompts using JSON schemas for controlled outputs.

### Focus:
- structured extraction
- response validation
- reduced ambiguity
- downstream AI workflow compatibility

---

# Problem Statement

Design and evaluate different prompt engineering techniques to accurately answer questions from a given text passage while minimizing:
- hallucination
- ambiguity

# Key Experiments

## Hallucination Analysis
Observed cases where models:
- added outside knowledge
- over-generalized responses
- introduced unsupported assumptions

### Example

Before refinement:
> “Football has financial issues and fan violence.”

After refinement:
> “Player injuries, match-fixing scandals, and competition pressure.”

# Prompt Refinement Strategy

The project repeatedly refined prompts by adding:
- strict constraints
- formatting rules
- extraction requirements
- balanced reasoning instructions
- fallback responses
- structured output formats

This significantly improved:
- factual accuracy
- consistency
- instruction adherence

---

# Comparative Analysis

| Prompt Type | Strength | Weakness |
|---|---|---|
| Zero-shot | Simple and fast | Higher hallucination risk |
| Few-shot | Better consistency | Can overfit examples |
| Role-based | Improved contextual tone | May introduce stylistic bias |
| JSON-based | Structured and reliable | Less flexible for ambiguity |

---

# Key Findings

- Prompt specificity directly improves response accuracy
- JSON-based prompting reduces ambiguity and improves structure
- Role-based prompting enhances contextual relevance
- Poorly designed prompts increase hallucination risk
- Prompt refinement significantly improves AI reliability
